# Data access

The ZD-MAST deposition is prepared as 17 checksum-verified archives under the
reserved Zenodo DOI [`10.5281/zenodo.21927440`](https://doi.org/10.5281/zenodo.21927440).
The record remains private until the author completes publication.

The package contains de-identified open peak tables, sample- and spectrum-level
feature matrices, public metadata, AST labels, patient-cluster and episode groups,
frozen split definitions, aggregate expected results and data dictionaries.

It does not contain original hospital identifiers, exact private timestamps,
identifier maps, vendor-native binaries, proprietary databases or private
prediction rows.

Third-party benchmark datasets, including DRIAMS, MS-UMG, MARISMa and Taiwan
MRSA/MSSA, are not redistributed. Users must obtain them from their original
repositories under their own licenses.

Archive identities and SHA-256 values are frozen in `manifests/`.

The data license is CC0 1.0 Universal as declared for the Zenodo record. The
software license in this repository does not change the dataset license.
