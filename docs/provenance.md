# Provenance

Candidate rc4 was derived non-destructively from checksum-verified rc3. Existing public IDs were preserved. Site A 2026 public IDs were assigned by independent fixed-seed random permutations outside the historical ID range. The 2026 spectrum vectors were regenerated from preserved mzML exports and their sample aggregates agreed with the frozen holdout matrix at maximum absolute difference 0. Exact dates were used only to freeze assignments and are not included in the candidate.

Candidate rc5 preserves rc4 spectra, features, labels, public IDs, and scientific results. It corrects the patient-species episode representation to sample-task granularity. The frozen ten-task primary analysis was independently reproduced from public IDs, public splits, and rc5 matrices in the exact historical software environment.
